# 🦎 抓包變色龍 (The Chameleon)

派對桌遊《The Chameleon》的繁體中文網頁版。**純靜態網頁、零後端**，可直接部署在 GitHub Pages。

## 怎麼玩

**主持人（一支手機／平板）**

1. 開新遊戲 → 選人數（3–8）與主題類別（或隨機）
2. 按「生成身份」→ 畫面出現一張 QR Code
3. 其他人用手機相機掃 QR，各自點選座位號，就會看到自己的身分
4. 大家都掃完 → 按「開始遊戲」→ 畫面顯示 4×4 題目表
5. 一局結束按「下一局」，會產生新的 QR（大家重掃一次）

**玩家**

- **平民**：拿到一個座標（例如 `B3`），題目公佈後對照那一格就是秘密詞
- **變色龍**：不知道秘密詞，只知道主題，要從別人的線索推測並裝作自己也知道

輪流每人講一個詞當線索 → 討論 → 同時投票指認變色龍。投錯變色龍贏；被抓到則變色龍有一次猜詞機會。

## 為什麼不用後端

一局的全部資訊（主題、秘密詞格子、變色龍座位、人數、起始玩家）編碼在網址的 `#` 片段裡。
`#` 之後的內容**不會送到伺服器**，只在各自手機上解讀 —— 所以不需要資料庫，也不需要連線同步。

代價：主持人畫面無法顯示「已加入 4/6 人」，口頭確認即可。

## 擴充題庫

編輯 `data/topics.json`，每張主題卡固定 **16 個詞**，依序填入 4×4 格子（`A1 B1 C1 D1` / `A2 B2 C2 D2` / …）：

```json
{ "id": "your_id", "name": "分類名稱", "emoji": "🎯",
  "words": ["詞1", "詞2", "...共 16 個..."] }
```

`id` 必須不重複，而且**不要改動既有的 id**（舊 QR Code 會失效）。

## 本機測試

```bash
python3 -m http.server 8000
# 開 http://localhost:8000
```

> 手機要掃得到 QR，網站必須部署在手機連得到的網址（GitHub Pages 或同網段的電腦 IP）。
> 直接用 `file://` 開啟會無法載入題庫。

## 部署到 GitHub Pages

Settings → Pages → Source 選 `main` 分支的 `/ (root)`，推上去就好，不需要建置流程。

## 檔案結構

```
index.html          所有畫面
css/style.css       樣式（深色、手機直式優先）
js/app.js           遊戲邏輯與路由
js/qrcode.min.js    QR 產生器（qrcodejs 1.0.0，已內含）
data/topics.json    題庫
```
